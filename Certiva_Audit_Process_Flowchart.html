Different Situations — Key Variants

How the process changes depending on standards and audit scope

🔐 ISMS (ISO 27001) Scope

  • FR.218 Application Review gains a reviewer co-signature slot (3 signers total).
  • Stage 1 Report uses FR.231 from the 27001/ template folder. Reviewer must also sign.
  • Stage 2 / Surveillance Report uses FR.229 (ISMS-specific, 24 tables). Reviewer must also sign.
  • ISMS auditors have no per-standard EA code filter — all 27001-qualified auditors appear in the picker.
  • FR.229 header tables 1–4 & 11 have the same fill structure as FR.232. Clause checklists (tables 5–10, 12–24) are filled manually by auditors on-site.

🏥 MDQMS (ISO 13485) Scope

  • Stage 1 Report uses FR.231-1 (MDQMS variant, from 13485/ folder).
  • Stage 2 / Surveillance Report uses FR.232-1 (MDQMS audit report).
  • No additional reviewer signature required (unless combined with FSMS/ISMS).
  • All other steps (FR.223, FR.224, FR.225, FR.233) use MDQMS copies from the 13485/ template folder.

🔗 Integrated Audit (e.g. ISO 9001 + ISO 27001)

  • Stage 2 and Surveillance ZIPs contain two audit reports: FR.232 (from base group) AND FR.229 (from isms group).
  • Stage 1 contains only one FR.231 (base version; deduplication prevents a second copy from the ISMS branch).
  • FR.223, FR.224, FR.225, FR.230, FR.211 appear once each per standard group in the ZIP.
  • FR.233 appears once only (primary group — base if QMS is included).
  • Certification Committee must collectively cover all EA codes for all included standards.
  • Reviewer signature required on both FR.232 and FR.229 for integrated FSMS+ISMS audit.

✍️ Signing Rules — All Audits

  • All signatures are visual only. No OTP anywhere on the platform.
  • FR.220 / FR.221: GM signs first; client is gated until GM signs.
  • FR.224: Private per person — each team member can only see and sign their own copy.
  • FR.225: Lead uploads → team signs → org employees sign.
  • FR.231 / FR.232 / FR.229: Lead Auditor signs. If FSMS or ISMS scope, reviewer co-signs.
  • FR.233: Committee members sign in order → Cert Manager signs last. Client cannot view this document.
  • Certificate: Pre-signed before upload. No additional signature step in platform.
